# 47 - Online Library Management System (Athenaeum)

A comprehensive, classic library and archival management platform built with React 18, Vite, Tailwind CSS, and Zustand.

## Features
- **Card Catalog**: Real-time availability lookup, Library of Congress (LOC) classification, ISBN search, and genre filtering.
- **Borrowing & Hold Protocol**: 14-day standard circulation periods with automatic overdue fine computation ($0.50/day) and waitlist queue management.
- **Curator Desk**: Librarian console to accession new titles, edit stock volumes, and retire damaged copies.
- **Archival Reports & Metrics**: Most-borrowed titles leaderboard, delinquency tracker, and recall dispatch system.
- **Classic Visual Identity**: Rich wood-brown (`#451a03`) and warm parchment palette with Cinzel serif and JetBrains Mono typography.

## Run Locally
```bash
npm install
npm run dev
```
Runs on port `3047`.
