# Project 32: Organic Farm-Fresh Online Grocery (Harvest & Hearth)

An organic farm-direct grocery e-commerce and cold-chain logistics platform built with React 18, Vite, TailwindCSS, and Zustand.

## Features
- **Fresh Green & White Theme**: Crisp agrarian aesthetic (`#f0fdf4`, `#16a34a`, `#15803d`, `#ffffff`) with Plus Jakarta Sans typography.
- **Smart Farm Basket & Substitution Engine**: Itemized unit scaling with automatic out-of-stock substitution policy selection (Organic Match, Call First, Refund).
- **Scheduled Cold-Chain Delivery Slots**: Flexible window selection (Express, Fresh Morning, Eco Saver).
- **Promo Code Engine**: Real-time discount validation (`HARVEST20` and `FRESH10`).
- **IoT Cold-Chain Telemetry Tracker**: Real-time refrigerated van sensor temperature tracking (2°C to 4°C safe zone) from farm packing to doorstep.

## Getting Started
```bash
npm install
npm run dev
```
