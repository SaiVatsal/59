# CoralHope — Charitable Giving & Transparent Donation Ledger

A coral-and-white styled charitable donation, campaign discovery, and cryptographic transparency ledger platform built with React 18, Vite 5, Tailwind CSS, and Zustand.

## Features
- **501(c)(3) Campaign Catalog**: Browse verified non-profit initiatives across pediatric healthcare, clean solar water filtration, and STEM educational equality.
- **Real-Time Progress Bars**: Animated funding status tracking with goals, days remaining, and backer counts.
- **Direct Impact Transparency Ledger**: Public, tamper-evident transaction logs tracking vendor payouts, equipment purchase orders, and audit statuses.
- **Automated Tax Receipts**: Instant IRS-compliant 501(c)(3) tax deduction certificate generation with cryptographic transaction hashes.
- **Campaign Creator**: Verified non-profit organizations can publish new funding initiatives with structured allocation plans.

## Running Locally
```bash
npm install
npm run dev
```
Port: `http://localhost:3041`
