# Project 23: Online Art Gallery (Atelier Vernissage)

An editorial fine art gallery and auction platform built with React, Vite, TailwindCSS, and Zustand.

## Features
- **Cream and Charcoal Haute Palette**: Cream background (`#fdfbf7`, `#f7f4ed`), rich charcoal (`#1c1917`), antique bronze accents (`#b89f7e`), and Cormorant Garamond serif typography.
- **Large Image-First Masterwork Showcase**: Curated exhibition view with high-res photography, physical dimensions, and provenance notes.
- **Live Bidding Auction Lots**: Real-time lot countdowns, current highest bids, and interactive bid incrementing.
- **Artists & Studios Directory**: Master profiles detailing origins, gallery representation, and catalogued works.
- **Private Vault & Custody Ledger**: Instant art acquisition flow with minted provenance hashes and certificate archiving.
- **Consignment Submission Studio**: Artist intake form to list and price original works.

## Getting Started
```bash
npm install
npm run dev
```
