# Project 55: Sports League Management System (Apex Premier League)

An official sports league management, live score center, fixture generator, and ticketing platform built with **React 18 + Vite 5 + Tailwind CSS 3.4 + Zustand 4.5**.

## Features
- **League Standings & Live Table**: Real-time table calculation (MP, W, D, L, GF, GA, GD, Points, Form badges).
- **Matchday Fixture Hub**: Live match clock, goals, yellow/red cards timeline.
- **Official Referee & Scorekeeper Console**: Instant score and discipline event recording with automatic table recalculation.
- **Golden Boot & Top Performer Statistics**: Player leaderboard tracking goals, assists, and clean sheets.
- **Team Roster Dossiers**: Squad profiles with positions, jersey numbers, ratings, and market valuation.
- **Matchday Ticketing & QR Pass Generation**: Interactive stadium tier selection with QR pass issuance.
