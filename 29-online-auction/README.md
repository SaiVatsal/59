# Project 29: Real-Time Online Auction System (Apex Auctioneer)

A high-stakes luxury auction and proxy bidding platform built with React 18, Vite, TailwindCSS, and Zustand.

## Features
- **High-Stakes Deep-Red & Black Palette**: High-contrast theme (`#09090b`, `#ef4444`, `#dc2626`) with Orbitron and JetBrains Mono countdown typography.
- **Live Floor & Dynamic Countdown Timers**: Anti-sniping safeguard automatically extends countdown clocks by 60 seconds whenever last-minute bids land.
- **Proxy Auto-Bidding Engine**: Automated incremental counter-bidding up to user-defined maximum ceilings.
- **Consignment Studio**: Add lots with custom reserves, inspection conditions, and duration tiers.
- **Won Lots & Escrow Settlement**: Manage escrow funds release and Brinks armored courier transit dispatch.

## Getting Started
```bash
npm install
npm run dev
```
