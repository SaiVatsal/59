# 48 - Feedback Management System (PulseFeedback)

An enterprise customer feedback, CSAT, and NPS intelligence system built with React 18, Vite, Tailwind CSS, and Zustand.

## Features
- **Multi-Channel Feedback Stream**: Automatic sentiment classification (Positive, Neutral, Negative, Urgent Triage), CSAT stars, and NPS ratings.
- **Customer Survey Portal**: Interactive survey form with live star-rating selector and 0-10 Net Promoter Score slider.
- **Survey Instrument Builder**: Create and publish custom campaigns across diverse product and operational categories.
- **Triage & Resolution Workflow**: Status updater (New, Under Review, Resolved) with immediate dispatch responses.
- **Trend Analytics Dashboard**: Real-time NPS calculation, CSAT averages, and sentiment distribution metrics.
- **Sky-Blue & White Theme**: Modern, rounded, high-contrast visual design.

## Run Locally
```bash
npm install
npm run dev
```
Runs on port `3048`.
