# Project 27: Food Recipe App (Saffron & Thyme)

An artisanal food recipe sharing platform with interactive Cook Mode built with React, Vite, TailwindCSS, and Zustand.

## Features
- **Warm Mustard & Terracotta Palette**: Cozy kitchen styling (`#fffbeb`, `#d97706`, `#c2410c`, `#7c2d12`) with Caveat hand-lettered script and Playfair Display serif typography.
- **High-Res Food Photography Cards**: Rich visual catalog with preparation timing, dietary badges, and community ratings.
- **Interactive Cook Mode**: Distraction-free, step-by-step cooking stepper with active countdown kitchen timers.
- **Dietary & Ingredient Search**: Filter across Mediterranean, Plant-Based, Gluten-Free, and High-Protein diets.
- **Personalized Cookbook Vault**: Save favorite recipes for quick access.
- **Community Recipe Submission**: Self-service portal to submit recipes with auto-generated dish visuals.

## Getting Started
```bash
npm install
npm run dev
```
