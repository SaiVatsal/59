# Project 34: Systems Engineering Discussion Forum (Nexus Discourse)

A threaded technical discussion platform built with React 18, Vite, TailwindCSS, and Zustand.

## Features
- **Muted Slate-Blue Theme**: Clean engineering aesthetic (`#f8fafc`, `#334155`, `#0284c7`) with Inter and JetBrains Mono typography.
- **Infinite Nested Comment Trees**: Recursively structured conversation nodes with parent-reply anchoring.
- **Algorithm Ranking & Sorting**: Hot, Top, and New filtering with score state management.
- **Moderator Controls**: Real-time thread Pinning and Locking safeguards.
- **Technical Categories**: Specialized boards for Distributed Systems, Kernel & Rust, Frontend Architecture, and Cryptography.

## Getting Started
```bash
npm install
npm run dev
```
