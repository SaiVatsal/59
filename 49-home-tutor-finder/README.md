# 49 - Home Tutor Finder (TutorMatch)

A verified in-home and virtual private tutoring marketplace built with React 18, Vite, Tailwind CSS, and Zustand.

## Features
- **Tutor Directory**: Subject-specific search, location filtering, hourly fee sorting, background check verification badges, and star ratings.
- **Tutor Profile & Scheduling**: Comprehensive dossiers with degrees, universities, subject specializations, and instant lesson booking with 1.5h session fee computation.
- **In-App Student-Tutor Chat**: Direct interactive messaging with instructor replies.
- **My Lessons Dashboard**: Track confirmed upcoming sessions, addresses, and cancellation options.
- **Tutor Onboarding Console**: Self-service profile builder for verified educators.
- **Warm Orange & White Palette**: Rounded photo frames, Outfit and Plus Jakarta Sans typography.

## Run Locally
```bash
npm install
npm run dev
```
Runs on port `3049`.
