# Project 30: Personal Portfolio Website (Kairos Thorne)

A high-performance personal portfolio, architecture case-study portal, and developer dossier built with React 18, Vite, TailwindCSS, and Zustand.

## Features
- **Monochrome & Electric Violet Accent**: Minimalist stark black & dark graphite theme (`#09090b`, `#18181b`, `#8b5cf6`) with Syne display headers and Space Grotesk labels.
- **Detailed Architectural Case Studies**: Deep dives covering distributed event streaming, kinetic spatial audio, and zero-knowledge PLONK verification.
- **Technical Skills & Career Trajectory**: Multi-column systems, UI, and security matrix alongside chronological role histories.
- **Embedded Technical Essays**: Dev notes covering kernel `io_uring`, kinetic pure CSS UI, and zero-knowledge proof benchmarks.
- **Live OpenGraph & SEO Inspector**: Interactive metadata testing sandbox with live social card rendering.
- **Spam-Protected Advisory Dispatch Form**: Interactive mathematical captcha verification and stateful dispatch queue.

## Getting Started
```bash
npm install
npm run dev
```
