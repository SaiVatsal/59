# HarvestRescue — Food Surplus & Waste Reduction Matrix

An eco-friendly food donation, circular food recovery, and waste reduction platform built with React 18, Vite 5, Tailwind CSS, and Zustand.

## Features
- **Surplus Food Directory**: Browse excess prepared meals, organic produce, fresh artisan bakery, and dairy batches with geolocation radius sliders.
- **Perishable Urgency Detection**: Real-time alerts for high-urgency perishable batches with dynamic expiry countdowns (<3 hours).
- **OTP Pickup Verification**: Two-way handoff confirmation code generated for claiming charities and shelters upon reservation.
- **Donor Surplus Batch Publisher**: Create surplus listings with portion estimates, weight metrics (kg), storage temperature requirements, and loading bay addresses.
- **Ecological Impact Engine**: Real-time calculated counters tracking meals rescued, CO2 kilograms diverted from landfills, and tree-growth equivalence metrics.

## Running Locally
```bash
npm install
npm run dev
```
Port: `http://localhost:3039`
