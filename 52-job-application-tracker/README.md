# 52 - Online Job Application Tracker (CareerPipeline)

An intelligent career and job application kanban pipeline manager built with React 18, Vite, Tailwind CSS, and Zustand.

## Features
- **Kanban Stage Funnel**: Visual stage transitions across Applied, Screening, Interview, Offer, and Rejected.
- **Interview Scheduling Calendar**: Log specific technical system design rounds, interviewer names, and calendar dates.
- **Application Dossier Modal**: Track target compensation ranges, attached resume versions, and personal prep notes.
- **Conversion & Success Analytics**: Live computation of application-to-interview and interview-to-offer funnel percentages.
- **Calm Slate & Gray-Blue Theme**: Distraction-free, modern interface with Plus Jakarta Sans and JetBrains Mono.

## Run Locally
```bash
npm install
npm run dev
```
Runs on port `3052`.
