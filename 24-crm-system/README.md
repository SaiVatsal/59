# Project 24: CRM System (PipelineOS)

An enterprise sales pipeline CRM and revenue forecast engine built with React, Vite, TailwindCSS, and Zustand.

## Features
- **Slate Blue Dashboard-Dense Palette**: Professional corporate interface (`#0f172a`, `#1e293b`, `#2563eb`) optimized for high-density enterprise account management.
- **Visual Sales Pipeline Kanban**: Stage progression (Lead-In → Discovery → Technical Evaluation → Proposal → Closed/Won) with dynamic win probability modeling.
- **Account & Contact Directory**: Filterable directory with ARR potential, executive designations, and direct mail/phone shortcuts.
- **Activity & Call Logging Stream**: Time-stamped executive meeting transcripts and action item tracking.
- **Automated Outbound Cadences**: Multi-stage email sequences with open/reply analytics.
- **ARR Revenue Forecasting**: Weighted pipeline probability computations and sales cycle duration metrics.

## Getting Started
```bash
npm install
npm run dev
```
