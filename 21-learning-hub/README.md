# Project 21: Learning Hub (LuminaLearn)

A comprehensive learning resource hub built with React, Vite, TailwindCSS, and Zustand.

## Features
- **Soft Lavender Palette**: Thoughtfully designed with calm purple and lavender hues (`#faf5ff`, `#a855f7`, `#6b21a8`) and rounded Quicksand typography.
- **Resource Library**: Articles, video masterclasses, and PDF syllabi with real-time category filtering and search.
- **Interactive Quiz Engine**: Knowledge assessments with instant scoring, feedback, and pass/fail accreditation thresholds.
- **Progress Tracking & Streaks**: Visual progress-bar-forward module cards, daily study streak counters, and XP milestones.
- **Instructor Studio**: Self-service console for instructors to publish curriculum and resources.
- **Accredited Certificates**: Digital credential generation with verification identifiers for passing test-takers.

## Getting Started
```bash
npm install
npm run dev
```
