# TealWealth — Personal Budget Planner & Financial Intelligence

A calm teal styled personal budget planner, envelope allocation engine, and savings goal tracker built with React 18, Vite 5, Tailwind CSS, and Zustand.

## Features
- **Budget Limits & Envelope Allocation**: Define and adjust monthly maximums per expense category (Housing, Groceries, Investments, Healthcare).
- **Overspend Detection Engine**: Real-time alerts when category outflows exceed assigned limits.
- **Savings Goals Milestones**: Track progress toward long-term wealth milestones (Emergency Fund, Travel, Solar Roofing) with automated percentage indicators.
- **Transaction Logger**: Fast income/expense transaction creation with automatic category spent reconciliation.
- **Executive Monthly Report**: Automated financial health statement detailing gross inflow, net retained capital, effective savings rate, and personalized AI advisory highlights.

## Running Locally
```bash
npm install
npm run dev
```
Port: `http://localhost:3043`
