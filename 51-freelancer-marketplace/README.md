# 51 - Freelancer Marketplace (TalentSphere)

An enterprise engineering and product design marketplace with milestone-based escrow contracts built with React 18, Vite, Tailwind CSS, and Zustand.

## Features
- **Job Board & RFP Portal**: Skill-tagged project listings, client trust ratings, budget types, and timeline constraints.
- **Milestone Escrow Contracts**: Step-by-step milestone funding, deliverable inspection, and automated disbursement.
- **Freelancer Portfolios**: Verified consultant profiles, hourly rates, case study galleries, and total earnings.
- **Bidding Engine**: Detailed proposal submissions with custom delivery day targets and cover pitches.
- **Client Job Creation Console**: Instant project publishing with escrow budget allocation.
- **Indigo & White Design**: High-contrast, clean professional layout with Plus Jakarta Sans and JetBrains Mono.

## Run Locally
```bash
npm install
npm run dev
```
Runs on port `3051`.
