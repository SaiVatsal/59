# Project 35: IMAX & Arena Ticket Booking System (Starlight)

A cinematic multi-tier ticket booking and concurrency seat-locking platform built with React 18, Vite, TailwindCSS, and Zustand.

## Features
- **Cinematic Deep-Purple & Black Theme**: High-contrast theater aesthetic (`#090514`, `#1a0b2e`, `#9333ea`, `#f43f5e`) with Space Grotesk and JetBrains Mono typography.
- **Interactive Multi-Tier Seat Map**: VIP Recliners, Premium Center, and Standard seating rows with real-time seat locking countdown.
- **Gourmet Concessions Bar**: Pre-order artisanal truffle popcorn and cold brew directly to your seat.
- **Discount Promo Validator**: Real-time coupon checkout (`PREMIERE20`).
- **Digital Apple Wallet-Style Pass**: Scannable QR pass with hall and seat reservations.

## Getting Started
```bash
npm install
npm run dev
```
